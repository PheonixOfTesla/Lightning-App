## Recording Tips

### Using QuickTime (Mac)
1. File → New Screen Recording
2. Click dropdown arrow → select device or screen area
3. For iPhone: connect via cable, select iPhone as source
4. Record, then File → Export → 1080p

### Using Chrome DevTools
1. Open Chrome → F12 → Toggle Device Toolbar
2. Select iPhone 14 Pro (390x844)
3. Use a screen recorder (OBS, Loom, or native)

### Video Specs
- Format: MP4, H.264
- Resolution: Native to device
- Frame rate: 30 fps
- No audio
- Target: Under 20MB per file
